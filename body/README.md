# Chuff Body

Placeholder — STL/Fusion 360 files land here once the body design is
finalised.

Design brief (from the Chuff spec):

- Egg-shaped body — suggesting a baby creature still learning.
- 3D printed in red PLA, referencing the chough's (*Pyrrhocorax
  pyrrhocorax*) red bill and legs.
- AMOLED window in the front face (Track A / ESP32-S3 board).
- No moving parts in v1; a single servo for a beak or tail wag is
  earmarked for v2.
- Must fit: the Waveshare ESP32-S3-Touch-AMOLED-1.8 board, a 3.7V LiPo
  battery, and (v2) an SG90 micro servo.
